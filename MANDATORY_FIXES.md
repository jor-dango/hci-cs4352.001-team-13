# Team 13 Mandatory Fixes

## Fix 1: Settings Clickable Area (H3: User Control and Freedom)
**Severity**: [1]
**Task**: Complex Task
**Issue**: The button for each of the settings is the text, but not the physical area around it including the arrow. Clicking on the arrow doesn't open the setting.
**Fix**: Increase area for clicking for each of the settings

## Fix 2: Text Size Consistency (H4: Consistency and Standards)
**Severity**: [2]
**Task**: All
**Issue**: The text size varies from page to page. On the Contract Analysis and summary page the text is much larger but on the settings page, everything is very small and hard to read.
**Fix**: Make the text the same size on the settings page as it is on the contract analysis page.

## Fix 3: Settings Password Screen Back Button (H3: User Control and Freedom)
**Severity**: [2]
**Task**: Complex Task
**Issue**: When clicking on settings, user is prompted to enter a password to confirm identity, but not given an option to exit out of that screen (for accidental clicking).
**Fix**: Add a back button so users can leave the settings without entering a password.

## Fix 4: Chat Response Bubble Clipping (H1: Visibility of System Status)
**Severity**: [1]
**Task**: Task 1
**Issue**: When asking a question about a scanned document, the response bubble is cut off, making the answer partially hidden or unreadable.
**Fix**: Ensure all response bubbles fully expand to show the complete text.

## Fix 5: View vs Compare Button Hierarchy (H4: Consistency and Standards)
**Severity**: [2]
**Task**: Task 2
**Issue**: On the Contract History page, the view and compare buttons are styled identically. View is typically used more often than compare.
**Fix**: Make "View" the primary action with a stronger color or filled style, and present "Compare" as a secondary button.

## Fix 6: Message Input Box Position (H4: Consistency and Standards)
**Severity**: [1]
**Task**: Moderate Task
**Issue**: Message box is not at the bottom of the screen, there's a lot of white space between the box and the nav bar. User confused whether screen is scrolled upwards.
**Fix**: Move the box to the bottom of the screen, just above the nav bar. Follows established convention for messaging interfaces.

## Fix 7: Unsaved Document Warning (H5: Error Prevention)
**Severity**: [3]
**Task**: Simple Task
**Issue**: After uploading a document, if you don't click "save to archive" and click to a different tab, the contract is not saved.
**Fix**: Add a warning such as "Leave without saving?" to prevent users from accidentally switching tabs if they intend to save the contract.

## Fix 8: General Aesthetic Improvements (H8: Aesthetic & Minimalist Design)
**Severity**: [Medium]
**Task**: All
**Issue**: Visual elements lack cohesion, spacing, and clarity, making the app appear unappealing or unfinished. Poor visual hierarchy affects user engagement.
**Fix**: Improve layout spacing, use consistent color themes, add clear section headers, and enhance typography.

## Fix 9: Back Button Consistency (H4: Consistency and Standards)
**Severity**: [Medium]
**Task**: Navigation
**Issue**: The back button is shaped inconsistently across screens, making the UI feel unstable and navigation unpredictable.
**Fix**: Standardize the back button's size, shape, icon style, and placement across all pages.

## Fix 10: Information Discoverability (H6: Recognition Rather Than Recall)
**Severity**: [High]
**Task**: Finding Information / Understanding Features
**Issue**: Important information is difficult to locate due to unclear labeling, lack of hierarchy, and hidden content.
**Fix**: Improve discoverability with clearer labels, structured sections, intuitive grouping, and dashboard-style navigation.

## Fix 11: Full Container Clickability (H2/H7: Match System & Real World / Flexibility)
**Severity**: [Medium]
**Task**: Navigating to Linked Content
**Issue**: Clickable links are limited to the text itself, rather than the entire box or section. Users expect the whole card/tile to be tappable.
**Fix**: Make entire containers (cards, rows, boxes) interactive, not just the text. Add hover/touch feedback.

## Fix 12: Section-Specific Questions (H3: Freedom)
**Severity**: [1]
**Task**: Task 2
**Issue**: When you click "ask a question", it opens a new page. If the user has a question on a certain part of the paragraphs, they would have to type everything out.
**Fix**: Add a small button under each section to make asking questions easier.

## Fix 13: Information Overload (H8: Minimalism)
**Severity**: [3]
**Task**: Task 1
**Issue**: The user is given too much information all at once. Too many words can be overwhelming at first glance.
**Fix**: Shorten the summary, use bolding to make important parts stand out.

## Fix 14: Back Navigation from Summary (H5: Error Presentation)
**Severity**: [3]
**Task**: Task 1
**Issue**: There should be a way to go back after seeing the summary. The user may want to make changes and completely change or delete the document.
**Fix**: Add a way to go back to make changes and add a delete contract button.

## Fix 15: Preferences Discovery (H6: Recognition)
**Severity**: [3]
**Task**: All
**Issue**: There are no indications in other pages for the filtering options which is very important when comparing contracts. Users had to toggle between pages to even see they can state their own preferences.
**Fix**: Mention updating preferences and concerns when looking at the contracts.
